# Метод A — общий реестр и формат для авторов

Каждый автор пишет свой кусок мира **вручную**: придумывает участников и операции. Куски стыкуются через общие
участники из этого реестра (магазины, арендодатели, P2P-трейдеры), поэтому сеть получается связной, как настоящая.

## Формат (строго)

Папка автора: `synthetic/A_llm/<prefix>/`, два файла.

`tx.csv` — операции мира:
```
src,dst,date,amount,channel
c1_courier_aliya,c1_collector_card_a,2026-07-03,48500,intra
```
- `src`, `dst` — хендлы участников (латиница, цифры, `_`). Свои участники — с префиксом автора (`c1_…`).
- `date` — `YYYY-MM-DD`; можно и вне июля 2026 (июнь/август) — такие отфильтруются при сборе.
- `amount` — тенге, число (копейки допустимы: `12345.50`).
- `channel` — `intra` (внутри банка) или `inter` (в другой банк — при сборе исчезнет).
- Внешние отправители/получатели вне банка/вне истории — префикс `ext_` (например, покупатель из другого банка).

`actors.csv` — описание **своих** участников (включая seed):
```
handle,functional_role,involvement,is_known,archetype,note
c1_courier_aliya,peripheral,criminal,true,закладчик,получает оплату за клады, сдаёт выручку сборщику
```
- `functional_role` ∈ consolidator / transit / distributor / terminal / coordinator / peripheral — **по замыслу** (что счёт делает в твоей истории).
- `involvement` ∈ criminal / legit.
- `is_known` — `true`, если клиент в списке правоохранительных органов (seed). Seed — нижний уровень: курьеры, закладчики, дропы.
- `archetype` — короткое имя типажа (по-русски), `note` — зачем счёт существует (одна строка, без запятых или в кавычках).

## Правила стыковки

- В `tx.csv` в колонке `src` — **только свои** хендлы (`<prefix>_…`) или `ext_…`. Операции от имени общих участников
  (`hub_…`, `x_…`) пишет их владелец. В `dst` можно любых: свои, общие, `ext_…`.
- Общих участников в свой `actors.csv` не добавлять.
- Хендлы чужих авторов (`c2_…` у автора `c1`) не использовать — связь между ячейками только через общих участников.

## Общие участники

Владелец `h` (легальная экономика города) — пишет их исходящие: зарплаты, поставщики, аренда, владельцы, их сотрудники.

| Хендл | Кто |
|---|---|
| `hub_grocery_1` … `hub_grocery_4` | продуктовые магазины у дома |
| `hub_bazaar_stall_1` … `hub_bazaar_stall_3` | точки на рынке (одежда, овощи, телефоны б/у) |
| `hub_cafe_1`, `hub_cafe_2` | кафе / донерная |
| `hub_taxi_park` | таксопарк (водителям платит выручку, от водителей получает аренду машин) |
| `hub_landlord_1` … `hub_landlord_4` | частные арендодатели квартир |
| `hub_phone_shop` | магазин телефонов и аксессуаров |
| `hub_auto_parts` | автозапчасти / СТО |
| `hub_car_dealer_used` | перекуп подержанных авто |
| `hub_gym` | фитнес-клуб |
| `hub_pharmacy` | аптека |
| `hub_beauty_salon` | салон красоты |
| `hub_construction_firm` | стройфирма (много рабочих на зарплате) |
| `hub_furniture` | мебельный магазин |
| `hub_pawnshop` | ломбард |
| `hub_tutor_center` | учебный центр / репетиторы |
| `hub_wedding_hall` | тойхана (банкеты, предоплаты) |

Владелец `c4` (оптовое звено) — пишет их исходящие:

| Хендл | Кто |
|---|---|
| `x_wholesaler` | оптовый поставщик; ячейки платят ему за товар |
| `x_p2p_trader_1`, `x_p2p_trader_2` | P2P-трейдеры криптовалюты: покупают/продают USDT за тенге, клиенты и легальные, и из сети |
